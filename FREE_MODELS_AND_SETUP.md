# Aether 2.1.9-free

## Free models (no API key)

On first launch the app adds these providers automatically:

| Name | Base URL | Models |
|------|----------|--------|
| openai (Pollinations) | https://text.pollinations.ai/openai | openai, openai-fast |
| openai-fast (Pollinations) | https://text.pollinations.ai/openai | openai-fast, openai |
| LLM7 Free | https://api.llm7.io/v1 | gpt-4o-mini |

No Termux and no API key required for these online free endpoints.

## One-tap Termux / local models

Local/AntiGravity still needs Termux installed from F-Droid.
Use **Settings → Termux** and the existing setup probe; the app drives allow-external-apps and probes without manual shell knowledge.

## Collaboration rooms

Enable collaboration in the chat controls. Multiple providers can share work; the session merges the final answer into one response.
